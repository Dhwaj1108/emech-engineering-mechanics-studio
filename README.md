# EMECH Interactive Engineering Mechanics Studio

A self-contained virtual experiment and problem-solving studio for the Engineering Mechanics mini-project. Open the HTML file in a modern browser; no installation, API key, or internet connection is needed.

## What it includes

- Coplanar force resultant and moment solver with a rotatable 3D-style view
- Simply supported beam reactions, shear-force diagram, and bending-moment diagram
- Inclined-plane friction experiment
- Symmetric triangular truss solver
- Composite-area centroid solver with signed areas for cut-outs
- Rectangle, circle, and hollow-circle moment-of-inertia calculator
- Kinematics, work–energy, and vector calculators

In the force view, drag to orbit, scroll to zoom, or use the arrow keys. Values are saved locally in the browser where storage is available.
